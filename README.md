# Man Tik Tang — Portfolio

Personal portfolio site showcasing frontend development work across agency campaign sites, landing pages, and interactive/game projects for global brands (Cathay Pacific, Asia Miles, KFC, Pizza Hut, Rakuten, and more).

🌐 **Live:** [d-tmt.com](https://d-tmt.com)

## Tech Stack

| Category         | Technology                             |
| ---------------- | -------------------------------------- |
| Frontend         | React, React Router, React Three Fiber |
| Styling          | Tailwind CSS                           |
| Animations       | Framer Motion                          |
| State Management | Zustand                                |
| Analytics        | Google Analytics (react-ga4)           |
| Build Tool       | Vite                                   |
| Linting          | ESLint                                 |
| Deployment       | Netlify (auto-deploy from GitHub)      |

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

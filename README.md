## Tech Stack

| Category         | Technology                             |
| ---------------- | -------------------------------------- |
| Frontend         | React, React Router, React Three Fiber |
| Styling          | Tailwind CSS                           |
| Animations       | Framer Motion                          |
| State Management | Zustand                                |
| Build Tool       | Vite                                   |
| Linting          | ESLint                                 |

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
